# MoodLens
MoodLens is a modern AI-inspired sentiment analysis web application that detects the emotional tone behind text in real time.
Users can paste reviews, comments, messages, or feedback and instantly analyze whether the sentiment is positive, negative, or neutral through an immersive dashboard interface.

## Live Demo
https://mood-lens-peach.vercel.app/

## Features
* Real-time sentiment analysis
* Detects Positive, Negative & Neutral tone
* Polarity and Subjectivity analysis
* Sentiment keyword detection
* Instant analysis using JavaScript
* Premium glassmorphism dashboard UI
* Fully responsive design
* Warm aesthetic dark theme
* Press Enter to analyze instantly

## Tech Stack
* HTML5
* CSS3
* Vanilla JavaScript
* AFINN Sentiment Lexicon

## UI Highlights
MoodLens was designed with a modern AI dashboard aesthetic featuring:
* Glassmorphism panels
* Copper & amber gradient accents
* Split-screen workspace layout
* Animated sentiment metrics
* Responsive interface for desktop & mobile
